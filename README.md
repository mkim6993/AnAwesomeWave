# AnAwesomeWave

Turn phones into synchronized stadium concert wristband lights.

## Core Feature

Convert phones into large stadium concert wristband lights that display synchronized effects, similar to what popular bands use at their concerts. An operator controls what clients display through a dashboard. Clients connect to the server via WebSockets using a code or QR code.
